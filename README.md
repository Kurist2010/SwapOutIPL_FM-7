SwapOutIPL\
FM77AVシリーズでFD起動時のブートローダーにBASICモード、DOSモードそれぞれでDISK BIOSを置き換えるIPLです。\
実FDでも問題ないですが、D77ファイルにて構築が前提です。

使用例(標準の320KBフォーマットの前提)\
元のディスクイメージ(D77)に対して\
C=0, H=0, R=1をC=0, H=0, R=8にコピー\
C=0, H=0, R=2をC=0, H=0, R=9にコピー\
C=0, H=0, R=1にSwapIPL.binを登録\
C=0, H=0, R=4～5にBASICモード時のDISK BIOSを登録\
C=0, H=0, R=6～7にDOSモード時のDISK BIOSを登録

例えばF-BASIC V3.0にNEW7用DISK BIOSを設定するとそれで起動することが可能になります。\
(この場合、恩恵は初代AVのみになります。2DD機には恩恵があまりありません。)

SwapOutIPL\
FM77AVシリーズで起動時のブートローダーにBASICモード、DOSモードそれぞれ置き換えるIPLです。\
トラック0 セクタ4～9を使用します。
D77ファイルで作成してから実FDでの使用を考えています。

使用方法(標準のF-BASIC V3.0 DISK BASICの場合)\
元のディスクイメージ(D77)に対して\
C=0, H=0, R=1をC=0, H=0, R=8にコピー\
C=0, H=0, R=2をC=0, H=0, R=9にコピー\
C=0, H=0, R=1にSwapIPL.binを登録\
C=0, H=0, R=4～5にBASICモード時のDISK BIOSを登録\
C=0, H=0, R=6～7にDOSモード時のDISK BIOSを登録

初期のFM-NEW7用ブートローダーを登録するとそれで起動することが可能になります。\
(恩恵は初代AVのみになります。2DD機にはあまり恩恵がありません。)
